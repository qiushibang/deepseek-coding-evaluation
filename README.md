# 真实项目里的 Coding 模型评测

把模型放进自己的项目，看它能否把需求做完，再比较时间和成本。

这是我围绕 **OpenCareer 招聘助手后台开发**进行的编程模型评测分享：四个模型、六道工程任务、24 次独立有效执行。使用 Pi Coding Agent（编程代理执行框架）提供相同的读文件、写文件、编辑、终端执行工具，分别进行新增功能和问题修复。

**[▶ 打开动态演示](https://qiushibang.github.io/deepseek-coding-evaluation/)** · [评测方法](docs/methodology.md) · [六道题说明](docs/tasks.md) · [逐题结果](docs/results.md) · [录屏讲解提纲](coding-benchmark-story/讲解提纲.md)

> 这是历史实验的公开整理版，分享评测思路和汇总数据。原始项目快照、隐藏测试及完整会话未公开，因此无法只凭本仓库独立复现全部实测。结果按本轮有效题面和验收口径整理，未重新调用模型复跑；它不构成通用能力排行榜。

## 四模型结果

| 模型 | 通过题数 | 时间 / 分钟 | 工具调用 | 估算费用 / 人民币 | 词元消耗 | 输入缓存命中率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| DeepSeek V4.1 Flash | 6/6 | 20.08 | 312 | ¥2.73 | 13,051,616 | 98.26% |
| GPT-6.1 Sol | 6/6 | 22.18 | 113 | ¥10.27 | 2,358,731 | 89.00% |
| GLM 5.3 | 6/6 | 30.88 | 221 | ¥5.35 | 5,718,247 | 97.40% |
| Claude Opus 5.5 | 6/6 | 26.14 | 93 | ¥29.02 | 3,145,548 | 92.90% |

时间为六题有效执行时间累加，不含准备、预检和独立判题。费用是约定单价估算，**DeepSeek V4.1 Flash 使用高峰价**，不是账户实扣；美元按实验采用的 1 美元＝6.7330 元换算。缓存统计来源不一致，不用于严格横向排名。详见[指标与费用口径](docs/metrics.md)。

这组任务中，Flash 最快、估算费用最低，GPT 词元消耗最少，Opus 工具调用最少。四者都通过六题，说明这套题目对完成率的区分度有限。更复杂工程中的优势仍需增加难度和重复实验后验证。

## 本地打开演示

无需模型密钥，也无需安装第三方依赖。在仓库目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/>。也可以直接用浏览器打开 `coding-benchmark-story/dist/index.html`。共 14 幕，默认 16:9，支持 9:16 和 3:4；空格播放、左右键翻页、F 全屏、H 录屏模式。过程动画、代码和产品界面均为讲解示意。

## 下一轮怎么测

增加跨模块、并发和异常恢复任务；加入多轮澄清、长上下文与更多工具；每题重复多次，比较相同预算下的成功率、耗时和成本。新要求应在运行前确定，不回头给旧答案追加标准。
