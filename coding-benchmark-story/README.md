# 动态测评演示

14 幕，默认横屏 16:9，自动播放约 4 分 11 秒。支持 9:16 和 3:4 画幅。

在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 <http://127.0.0.1:4173/>；也可直接打开 `dist/index.html`。无需安装依赖，不调用模型接口。

空格播放或暂停；左右方向键翻页；F 切换全屏；H 进入或退出录屏模式；Home 回到开场。开启“讲解提示”可查看每幕提纲，录屏模式会隐藏控制界面。用自己的录屏软件和麦克风录制。

数据见[汇总](../data/model-summary.csv)，口径见[说明](../docs/metrics.md)。动画中的执行过程、终端和产品界面均为讲解示意，不代表现场运行或并发执行。四者 6/6 对应历史有效题面与验收口径；费用为估算，缓存范围不同。

本公开版采用系统字体，无外部字体或统计服务请求。原私有工作区和托管链接不包含在公开版中。
