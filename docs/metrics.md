# 指标、费用与比较边界

| 字段 | 含义 |
| --- | --- |
| 通过题数 | 按本轮有效题面和验收标准完成的题数，不是所有软件任务的正确率。 |
| 时间 / 分钟 | 六题有效模型执行时间之和，不含准备、预检、独立判题；不是并发墙钟时间。 |
| 工具调用 | 执行期间调用四类工具的累计次数，不直接代表代码质量。 |
| 估算费用 / 人民币 | 根据记录用量与约定单价重算，不等于账户实扣、订阅价格或完整实验总开销。 |
| 词元消耗 | 原汇总记录的累计 Token（词元，模型处理与计费的文本单位），包含输入和输出相关用量。 |
| 输入缓存命中率 | 缓存读取输入占对应输入的比例；分母不应包含输出。各模型统计来源不同。 |

## 本轮采用的单价

单位均为每百万词元。价格来自实验时保存的截图，是历史计算假设，不是实时价格。

| 模型 | 币种 | 未缓存输入 | 缓存读取 | 缓存写入 | 输出 |
| --- | --- | ---: | ---: | ---: | ---: |
| DeepSeek V4.1 Flash | 人民币 | 2.00 | 0.04 | 本轮无此项用量 | 8.00 |
| GPT-6.1 Sol | 美元 | 2.00 | 0.10 | 2.50 | 10.00 |
| GLM 5.3 | 美元 | 0.039 | 0.038 | 本轮无此项用量 | 4.80 |
| Claude Opus 5.5 | 美元 | 4.00 | 0.20 | 5.00 | 20.00 |

费用＝（未缓存输入×输入单价＋缓存读取×读取单价＋缓存写入×写入单价＋输出×输出单价）÷1,000,000。美元部分乘以实验采用的 **6.7330** 折算人民币；Flash 按用户选定的高峰价计算。先保留逐题精度，累加后再四舍五入。

公开的逐题文件保留原有合计词元与重算费用，但没有公开完整的分类计费用量和账户凭证。因此可复算汇总加法，无法仅凭这些文件独立复核每次接口账单。

## 缓存与可恢复错误

Flash 的 98.26% 来自本轮有效六题接口用量；其余三个模型来自历史平台截图，时间窗口与统计范围不同。不能将其解释为同一口径下的严格缓存排名。

工具报错记录分别为：Flash 5 次、GPT 20 次、GLM 19 次、Opus 1 次。可恢复的命令失败与最终未完成任务是不同概念，Opus 也不是零报错。数据来自历史汇总，本次公开整理未重新运行模型或重新计算原始会话中的调用数。

主比较只包含 Flash、GPT、GLM、Opus。早期 DeepSeek V4 Pro 为不同补充实验，不混入四模型对比。
