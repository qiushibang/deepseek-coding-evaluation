# 公开版的范围

本仓库用于分享真实项目编程评测的设计思路、整理后的历史结果和录屏演示。它以新的公开历史发布，不继承此前私人工作仓库中的提交与文件。

公开内容包括方法介绍、六道任务摘要、24 条逐题数值、四模型汇总、静态演示源码、讲解提纲和封面。公开身份仅保留作者 GitHub 账号及对应公开仓库地址。

没有公开笔试原文与私人答卷、个人联系方式、机器路径、密钥、账户截图、原始模型会话、响应标识、参考答案、隐藏测试、完整项目快照或第三方源代码归档。原始资料独立保留，不在本公开仓库中提供恢复包。

网站不调用模型、不采集录音或摄像头、不使用统计埋点，无需登录。公开版移除了外部字体请求，使用系统字体；若通过 GitHub Pages 访问，托管平台仍会处理正常网页访问请求。

本次整理验证了公开文件的敏感信息规则、数据加总及演示功能。自动扫描无法保证发现所有语义上的敏感信息，因此发布同时使用了文件白名单，只提供经过审阅的分享材料。公开文件不含原始判题证据，不应被描述为可以完整独立复现的基准。

如发现不适合公开的内容，请通过本仓库 Issue（问题反馈）说明文件位置，不要直接粘贴密钥或个人信息。
