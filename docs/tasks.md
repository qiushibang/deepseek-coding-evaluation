# 六道工程任务

任务来自 OpenCareer 招聘助手后台。下表是便于理解的场景摘要，**不替代原始完整题面与验收程序**。编号中的 F 表示 Feature（新增功能），B 表示 Bug fix（问题修复）。

| 编号 | 类型 | 通俗介绍 | 主要观察点 |
| --- | --- | --- | --- |
| F1 | 新增功能 | 招聘来源很多，一次抓不完时，记录进度，下次接着抓。 | 多来源游标、进度保存、续跑。 |
| F2 | 新增功能 | 让定时任务使用正确目录和角色下的工具，并处理需要审批的操作。 | 工具选择、权限与审批衔接。 |
| F3 | 新增功能 | 把一段时间内新增、变化的岗位和招聘源状态，汇成每日摘要。 | 时间窗口、岗位变化与来源健康汇总。 |
| B1 | 修复问题 | 某次抓取失败，不应误以为原有岗位都已下线。 | 失败向上传播，避免错误更新岗位状态。 |
| B2 | 修复问题 | 翻页时数据变化，可能出现重复或遗漏，需要有限度地恢复。 | 分页漂移识别、边界与有界恢复。 |
| B3 | 修复问题 | 抓取时复用连接，对短暂网络错误有限重试。 | 连接生命周期、瞬时故障与重试上限。 |

每题从相应的修改前代码开始。模型间工作区、会话和答案隔离；做题阶段不能读取隐藏测试与参考实现。题目摘要不包含原项目代码、业务数据和可还原私人环境的信息。
